# Weather Station
This project was built as part of the Connectors Training Program (Connectors Team – Faculty of Engineering, Mansoura University).
A simple and clean weather station project using Arduino Uno, DHT11 sensor, and a 128x64 SSD1306 OLED display. The system reads temperature and humidity from the DHT11 and displays them on a graphical OLED screen along with weather icons and UI elements
# Features
- Reads Temperature (°C) from DHT11
- Reads Humidity (%)
- Displays data on a 128x64 OLED (I2C)
- Clean & organized UI layout
- # Components 
- Arduino UNO
- Oled Display
- DHT11
- Jumper Wires
- Breadboard
